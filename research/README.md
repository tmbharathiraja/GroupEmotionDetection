# Research notebook

`EmotionRecognition.ipynb` is the original Colab research notebook with outputs and execution metadata stripped. It includes EDA, detector comparisons, pre-annotation, Label Studio evaluation, and majority-vote aggregation.

The notebook references the original Google Drive dataset paths and separate deep-learning/evaluation environments. Running the web demo does not require running this notebook or obtaining the dataset. See [research notes](../docs/research.md) for evaluation context and serving changes.

The two `*.original.txt` files preserve the original environment snapshots from Drive. They document the experiments; use the backend requirements for this application.
